# Web client feature spec

The web client presents the responsive public marketplace and account/listing interfaces described in the [product specification](../SPEC.md).

- Visitors can browse, search, filter, sort, and open public property listings.
- Signed-in owners can submit and manage their listings, including pending review status.
- Administrators can review submissions and manage listings.
- Use English interface copy and MMK price display for the initial release.
- Display illustrative sample content as samples, never as active offers.
